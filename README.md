# AI Agent 部署资产手册

一份面向所有角色的 AI Agent 部署资产管理指南。

## 这是什么

部署一个 AI Agent 需要管理 **8 大类 32 项资产**，涉及 **5 类角色**（个人使用者、团队协作、运维、迭代者、评测者）和 **6 个评估维度**。

本手册帮你：
- 快速定位自己需要关注的资产
- 理解每项资产对不同角色的作用
- 掌握评测、基准线、迭代的实操方法
- 了解抽象概念在具体工具（Claude Code、Cursor、QwenWork、企业 AI 中台）中的对应产物

## 如何使用

直接在浏览器中打开 `index.html` 即可。

这是一个自包含的单文件 HTML，无需安装任何依赖，支持：
- Tab 切换浏览 8 大类资产
- SVG 动画展示资产信息结构
- 落地对照表映射到具体工具
- 响应式布局适配移动端

## 内容结构

1. **概览** — 8 大类 32 项资产总览
2. **架构** — 6 层系统架构图
3. **资产结构** — SVG 动画展示资产层级关系
4. **角色视角** — 5 类角色各自关注什么
5. **资产明细** — 32 项资产逐项拆解（含基准线）
6. **落地对照** — 映射到 Claude Code / Cursor / QwenWork / 企业 AI 中台
7. **PM 案例** — 产品经理按三层管控模型维护的资产
8. **实操指南** — 评测 / 基准线 / 迭代方法论

## 技术栈

- 纯 HTML/CSS/JS，零依赖
- Lucide Icons（CDN: unpkg.com/lucide@latest）
- Google Fonts（Fraunces + Outfit）
- SVG 动画（原生 SMIL）
